# Irregular Words

Тренажёр неправильных английских глаголов: задания на формы глагола и распознавание инфинитива по транскрипции. Ответ можно ввести или выбрать из вариантов. Приложение показывает результат проверки и сохраняет счёт в cookie браузера.

## Структура

- [`api/`](api/README.md) — NestJS API: словарь, генерация и проверка упражнений, раздача фронтенда.
- [`web/`](web/README.md) — React, TypeScript и Vite: интерфейс тренажёра.
- `api/public/dictionary/dictionary.data.json` — словарь, загружаемый сервером в память. База данных не нужна.

Nx управляет сборкой и запуском приложений. В корне, `api/` и `web/` отдельные `package.json` и lock-файлы.

## Быстрый старт

Для локального запуска используйте Node.js 24 и npm. Все команды ниже выполняются из корня репозитория.

```sh
npm ci
npm run setup
npm start
```

`npm start` собирает оба приложения и запускает сервер:

- интерфейс — http://localhost:3000;
- API — `http://localhost:3000/api`;
- публичный словарь — `http://localhost:3000/public/dictionary/dictionary.data.json`.

Другой порт: `PORT=3001 npm start`.

## Разработка и сборка

| Команда | Назначение |
| --- | --- |
| `npm run build` | Собрать API и фронтенд в `api/dist` и `web/dist` |
| `npm start` | Собрать оба приложения и запустить сервер |
| `npm run build:start` | Собрать оба приложения и запустить сервер без Nx-задачи `serve` |
| `npm run api:dev` | Собрать фронтенд один раз и запустить API с отслеживанием изменений |
| `npm run dev --prefix web` | Запустить Vite с горячим обновлением и моками API |

В режиме `api:dev` изменения фронтенда требуют повторной сборки: `npx nx build web`, затем обновления страницы. Для работы над интерфейсом с моками используйте Vite; для проверки с настоящим API — общий сервер.

Корневой скрипт `web:dev` ссылается на отсутствующую Nx-задачу `web:dev`. Пока она не настроена, используйте `npm run dev --prefix web`.

Nx кеширует сборки в `.nx/`. Принудительная пересборка:

```sh
npm run build -- --skip-nx-cache
```

## Настройки

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт NestJS; в Compose — внешний порт контейнера |
| `VITE_API` | `/api` | Базовый адрес API для фронтенда, задаётся при сборке |

`VITE_API` можно задать в окружении или `web/.env`. Для общего сервера оставьте `/api`. Изменение переменной после сборки не меняет готовый фронтенд — его нужно пересобрать.

## Docker

При запуске через Docker локальная установка Node.js и зависимостей не требуется.

```sh
docker compose up -d --build
```

Приложение доступно на http://localhost:3000. Для другого внешнего порта:

```sh
PORT=3001 docker compose up -d --build
```

```sh
docker compose logs -f app
docker compose down
```

Без Compose:

```sh
docker build -t irregular-words .
docker run --rm -p 3000:3000 irregular-words
```

Образ содержит API, фронтенд и словарь; процесс работает от пользователя `node`. Локальные `.env` не попадают в образ. Адрес API передаётся при сборке через `--build-arg VITE_API=/api` или переменную `VITE_API` при запуске Compose.
